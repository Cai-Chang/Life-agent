# ADR 0005：模型对话与个人会话历史

日期：2026-11-26；范围：DEV-04。用户选择OpenAI兼容API，未授权把既有日程/待办自动发送给模型。

- 模型请求使用独立适配器，官方HTTPS端点固定为DeepSeek、通义北京/新加坡；百炼业务空间ID只能进入已知域名的受限子域，不接受任意URL。禁用HTTP重定向，防止转发Bearer凭据。校验JSON响应与文本长度，工具调用不执行，不返回内部推理正文。
- 只发送服务端给出的当前时区/时间、当前会话最近最多12轮完整成功对话和新消息，历史与新消息合计最多24000字符；不读取其他会话或业务表内容。模型输出仅作为普通文本展示。
- 密钥按已认证用户UUID存入服务端私有文件，0600且原子替换；配置目录默认`.local/model-settings`，Docker使用独立卷并由应用UID拥有。接口只返回配置状态/模型/服务商，不返回密钥；不进入浏览器存储、日志、数据库、Git或构建上下文。保存需CSRF和明确的数据发送同意；更换服务/地域/空间须重新填写对应密钥。
- 当前以主机文件权限保护凭据，没有宣称磁盘加密或跨服务器密钥管理。多实例部署的共享安全存储、密钥轮换与备份策略需另行设计。
- 0004显式创建conversations/messages。用户和空间由会话推导；所有历史、发送、重试与删除均检查归属。序号和会话/操作键/角色唯一约束保证消息顺序与幂等。同键不同正文拒绝。
- 发送先在持锁事务中保存用户消息和pending助理消息，提交后才访问外部服务；连接测试也在网络调用前释放认证事务。一个会话不能并发追加，两条有效生成租约/账号，新消息20条/分钟。租约120秒，网络连接/读取超时45秒，响应读取最多512KiB，回复最多16000字符；失败不自动再次付费调用。
- 完成时重新加锁检查租约token和有效期；旧响应不能覆盖重试，新消息后的旧失败轮次不允许重试。每轮最多初次调用加两次手动重试，用户消息不重复写入。失效pending在读取时推导为可恢复失败，不在GET里自动写数据或再次调用模型。
- 清除会话级联清除消息；操作记录只保留会话ID等元数据，不保留聊天正文。清除不删除日程、待办或模型配置，迟到响应也不能恢复已清除历史。
- 本阶段返回整条回复，pending状态可轮询恢复；SSE、MCP、Agent计划审批和任务执行分别留给DEV-05至DEV-07，模型不会直接触发写接口。
- 自动化测试注入明确测试模型；生产入口始终使用真实适配器，不提供网络失败后的模拟回复。E2E测试服务器放在scripts/e2e_api.py，不复制进应用Docker镜像。真实服务验收单独记录，不能以模拟服务成功代替。
